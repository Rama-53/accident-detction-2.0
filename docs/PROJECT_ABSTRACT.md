# Project Abstract

The **Accident Detection System 2.0** is a real-time smart city solution designed to automate traffic monitoring by fusing computer vision with physics-based analysis. Utilizing a hybrid architecture that combines **YOLOv11** for object detection and a custom **ResNet50** classifier for verification, the system identifies potential collisions with high precision while minimizing false positives. Built for seamless deployment and maintainability, the application is fully containerized using **Docker** and managed through rigorous **Git** version control. Once an accident is confirmed, it instantly alerts emergency services with location data and automatically archives forensic video evidence, providing a comprehensive command center that significantly reduces response times and enhances road safety.
